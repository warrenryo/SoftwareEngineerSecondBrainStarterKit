# SoftwareEngineerBrain

A local Obsidian vault for software engineering context, durable project knowledge, useful references, and quick captures.

## Start here

- [[AGENTS]] — operating rules and setup guide.
- [[CONTEXT]] — canonical destinations and context selection.
- [[10 - Projects/Projects Index]] — start or route project work.
- [[20 - Areas/Areas Index]] — ongoing cross-project practices.
- [[30 - Resources/Resources Index]] — external references.
- [[PROFILE-INVENTORY]] — Codex profile snapshot checked 2026-11-23.

## Lightweight daily loop

1. Read the matching project `Hub.md` and only its relevant links.
2. Put raw thoughts and sources in `00 - Inbox/`; promote verified, durable facts to one canonical project Knowledge note, Area, or Resource.
3. Keep repository and tracker records authoritative for live code and execution status.
4. At the end of a coding session, update the Hub if its status or next action changed, add a dated session note from [[Templates/Coding Session]], and add a short link to [[log]].

## Folder map

- `00 - Inbox/` — unprocessed captures
- `10 - Projects/` — project Hubs, sessions, and Knowledge notes
- `20 - Areas/` — ongoing responsibilities and practices
- `30 - Resources/` — references and source summaries
- `40 - Archive/` — inactive material
- `Attachments/` — media
- `Templates/` — reusable note structures

## Graphify

Graph outputs are derived data under `graphify-out/`. Query graph results against their source Markdown. Verify `INFERRED` edges before relying on them. This starter kit has no generated graph until useful source notes exist.
