# SoftwareEngineerBrain starter kit

A clean, independent Obsidian vault for software engineering context. This starter kit contains routing guidance, empty note templates, the Graphify Codex skill, and a dated inventory of the Codex profile checked on 2026-11-23. It does not contain project notes or credentials.

## Open it in Obsidian

In Obsidian, open **Manage vaults → Open folder as vault**, then choose this `SoftwareEngineerBrain` folder. Obsidian stores vault-specific settings in a new `.obsidian/` folder. Enable the core **Templates** plugin and set its template folder to `Templates` if those settings are not already present.

## First use

1. Read [[AGENTS]] and [[CONTEXT]].
2. For engineering work, create or open the matching project folder under `10 - Projects/` and start with its `Hub.md`.
3. Follow the install and profile notes in [[PROFILE-INVENTORY]] only when you need those tools. Confirm versions and authentication on the current machine before restoring a dated profile snapshot.
4. Keep the starter content as routing and templates. Add project-specific notes only when you have a verified source and canonical destination.

The current live profile list is in [[PROFILE-INVENTORY]]. The older portability bundle and Windows restore script remain in the sibling `MySoftwareEngineerVault/Codex Setup/` folder if that vault is available.
